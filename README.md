BlogSpace

BlogSpace is a simple blogging application built to practice RESTful routing and CRUD operations using Node.js and Express.js. Users can create blog posts, view all posts, view individual post details, edit posts, and delete posts.

Features
View all blog posts
Create a new post with a username and content
View individual post details, including its ID
Edit and update an existing post
Delete a post
Technologies Used
Node.js
Express.js
EJS
HTML
CSS
JavaScript
